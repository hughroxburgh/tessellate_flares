# TESSELLATE flare star catalogue

Website for stellar flares found in TESS full-frame images by the TESSELLATE transient search, published with
GitHub Pages at <https://hughroxburgh.github.io/tessellate_flares/>. Companion to the
[TESSELLATE asteroid catalogue](https://cheerfuluser.github.io/tessellate_asteroid/), and styled to match it
(same layout and tokens; red accent where the asteroids use purple).

The site is fully static: no server, no build step on GitHub. Everything under `data/` and the `assets/fig_*.png`
figures are generated by `code/build_site.py` in the FlareStars repository; the pages and scripts are hand-written.

## Layout

| path | contents |
|---|---|
| `index.html` | home: headline numbers, quick search, population figures, methods |
| `search.html` | browse every flare star: search by Gaia DR3 ID or position, filters, sorting |
| `star.html?id=<gaia dr3 id>` | one template for every star, filled from that star's data file |
| `assets/site.css` | shared styles |
| `assets/common.js` | shared helpers (data loading, search, formatting) |
| `assets/star.js` | star page: light curve, flare view, flare table, sky view |
| `assets/fig_*.png` | population figures (generated) |
| `data/summary.json` | headline numbers, sectors, figure captions, build id (generated) |
| `data/index.json` | one compact row per star for search (generated) |
| `data/stars/<digits 3-4 from the end of the ID>/<id>.json.gz` | one star (generated) |
| `data/tables/*.csv.gz` | stars, flares and flare peaks tables (generated) |

## Per-star data

Each star file is gzipped JSON, inflated in the browser (`DecompressionStream`). It holds the star's properties,
its light curve per sector in 30-minute bins with the fitted baseline, and every flare event: class, power-law
decay fit, extra peaks, localisation, and the residual light curve at full 10-minute cadence in a window around
the flare. Fluxes are stored as integers in units of 0.1 e-/s. Gzipped files keep the published site well under
the 1 GB GitHub Pages limit (about 4 KB per star, roughly 0.2 GB at 50,000 stars).

Gaia DR3 source IDs always end in a multiple of 4, so files are sharded by the 3rd and 4th digits from the end.

## Libraries

- [uPlot](https://github.com/leeoniya/uPlot) 1.6.32 (MIT), from jsDelivr, for the light curves.
- [Aladin Lite v3](https://aladin.cds.unistra.fr/AladinLite/) from CDS, for the sky view (PanSTARRS DR1 colour
  north of Dec −29°, DSS2 colour elsewhere; Gaia DR3 sources from VizieR).

## Preview locally

The pages fetch their data, so open them through a local web server rather than as files:

    python -m http.server 8765

then visit <http://localhost:8765/>.
